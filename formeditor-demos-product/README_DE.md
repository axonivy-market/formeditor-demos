# Axon Ivy Form Editor Demos

Der Axon Ivy Form Editor ist ein benutzerfreundliches Design-Tool, mit dem Sie Formulare visuell erstellen können. Anstatt Code zu schreiben, können Sie Elemente einfach per Drag-and-drop platzieren, um die Benutzeroberfläche zu gestalten. Das macht die Entwicklung schneller und für alle zugänglicher.

Dieses Demo-Projekt zeigt, wie Formulare innerhalb eines Prozesses erstellt und verwendet werden können. Es bietet ein einfaches und praxisnahes Beispiel, mit dem Nutzer nachvollziehen können, wie man ein Formular entwirft, mit Informationen verknüpft und Schritt für Schritt damit interagiert – selbst ohne tiefgehende technische Kenntnisse.
