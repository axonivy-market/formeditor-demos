# Axon Ivy Form Editor Demos

Der Axon Ivy Form Editor ist ein benutzerfreundliches Design-Tool, mit dem du Formulare visuell erstellen kannst. Anstatt Code zu schreiben, platzierst du Elemente für deine Benutzeroberfäche einfach per Drag-and-drop. Das macht die Entwicklung schneller und einfacher.

Dieses Demo-Projekt zeigt, wie Formulare innerhalb eines Prozesses erstellt und verwendet werden können. Es bietet einfache und praxisnahe Beispiele, mit denen Du nachvollziehen kannst, wie man ein Formular entwirft, mit Informationen verknüpft und sie nutzt – selbst ohne tiefes Entwickler Know-How.
